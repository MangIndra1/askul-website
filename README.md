# AsKul — Asisten Kuliah

Dashboard produktivitas pribadi untuk mahasiswa: focus timer (Pomodoro), to-do list, journal, kalender deadline, growth XP, dan integrasi musik.

## Tech stack
- Next.js 16 (App Router, Turbopack, React Compiler)
- TypeScript
- Tailwind CSS v4
- Supabase (Auth + Postgres)

## Menjalankan secara lokal
\`\`\`bash
npm install
npm run dev
\`\`\`
Buka http://localhost:3000
